# ALISH CARS

Лендинг «Автомобили из Китая под ключ». Сделан 1 в 1 по макету `reference/mockup.png`.

- Vite + React + TypeScript, иконки lucide-react
- Десктоп (≥1100px) свёрстан в пикселях макета (1024) и масштабируется под экран
- Узкие экраны — отдельная мобильная вёрстка
- Номер WhatsApp задаётся в `src/App.tsx` (константа `WHATSAPP`)

```
npm install
npm run dev
```
